# OpenStories launch kit

Drafts for X, Hacker News and Product Hunt, plus the assets they reference. Written 2026-09-19 against v1.0 (1,628 stories, 20 industries, 104 domains).

**Read `PRE-LAUNCH.md` first.** It lists what has to be true in the repository before any of this is posted. The copy below is written to be defensible once those items are done; posting it before then invites the one thread you do not want on HN.

Files:

- `PRE-LAUNCH.md`: the gate.
- `x-thread.md`: 6 tweets with the images to attach.
- `show-hn.md`: title and body.
- `product-hunt.md`: tagline, description, first comment.
- `../site/assets/`: `og.png` (1200×630), `term-*.png` (terminal renders from real output), `ui-*.png` (dashboard captures).
