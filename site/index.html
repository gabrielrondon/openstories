    1-click MCP setup

    Two commands. Your agent reads the library before it writes.

    1. Install the binary. go install github.com/gabrielrondon/openstories/cmd/openstories@latest. Zero dependencies, the library is embedded.
    2. Register the MCP server. openstories install claude or openstories install cursor. Restart the client.
    3. Ask before you build. "What does production say about magic links?" The agent calls search_stories and gets the criteria, the edge cases and the citations.
    4. Lint the spec. openstories eval --file spec.md in CI, or the evaluate_spec tool from inside the agent.

    Also: openstories serve runs the web dashboard and a REST API (/api/stories, /api/eval) on your machine. openstories harvest --repo mines a public repo's issues into new stories.

    Get it

    Stories are Markdown files with YAML front matter under stories/<industry>/<domain>/. A story needs a real citation to be merged. Contributing guide.
