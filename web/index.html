Instalação 1-Click no Claude Desktop & Cursor

Zero configuração manual. O próprio CLI injeta os servidores MCP locais.

Claude Desktop: Automático
openstories install claude
Cursor IDE: Automático
openstories install cursor

Após rodar o comando acima, quando você pedir para o Claude ou Cursor:
"Escreva uma feature de estorno parcial de pagamentos", o modelo invocará a ferramenta evaluate_spec do OpenStories para prever falhas reais antes de codificar!
